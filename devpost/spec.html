Journey reveals

Open a behavior to see how the product requirement maps into the system.

Full decode

The typed client sends { text, audience } to POST /api/decode. The Next.js route validates with Zod, builds the audience-aware prompt, calls streamText, and returns the AI SDK stream. The browser fills TL;DR, Analogy, Jargon Buster, and Takeaway in order.

Section retry

The failed card keeps the current source and audience. Its retry control sends { text, audience, section } to POST /api/retry-section. Only that card returns to streaming; completed cards are untouched.

Secrets and boundaries

The Gemini key exists only in the server environment. .env is ignored, .env.example contains names only, and the browser never calls Gemini directly. There is no database or cross-session storage.

One useful first check

Before building the UI pipeline, verify a fresh restricted Google AI Studio key, a currently available fast model, free-tier quota, and one minimal streaming request. The provider contract is documented, but account and quota availability can change.

Provider contract

Google Gemini through the Vercel AI SDK keeps the chosen streaming architecture type-safe.

Base URL: @ai-sdk/google
Request: route handler, Zod-validated input, streamText, server-side API key, and a configured Gemini model.
Docs: AI SDK, Google provider, and Zod.

Scope-change architecture

Two new paths deepen the explanation without adding a separate service.

/api/upload

Accepts PDF/TXT multipart uploads, extracts text with native decoding or pdf-parse, and returns editable text.

Concept Map

Gemini returns validated nodes and edges after the four cards; React Flow renders the interactive relationship layer.

/api/fetch-url

Safely fetches public HTML, rejects private or unsupported destinations, and returns editable readable text.
